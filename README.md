# Reservoir Time Machine

**AI-assisted 4D seismic monitoring and interpretation**
APGCE GeoHackathon 2026 · Challenge 3

## Purpose

Reservoir Time Machine compares Baseline and Monitor seismic surveys, finds candidate changes, and organizes evidence for geoscience and reservoir-engineering review.

## Workflow

Baseline + Monitor → Seismic Attributes → Statistical and ML Screening → Finding-Directed Visualization → Interpretation → Investigation Support

## Features

- Automated screening of completed analysis coverage
- Finding-centered seismic sections and 4D comparison
- Statistical and eligible classical ML evidence
- Well-data context where association is supported
- Grounded interpretation and investigation summaries
- Presentation and technical-report exports

## Results

Bounded Challenge 3 analysis and seven-page rendering have been validated. The current findings cover **2 of 28 planned tiles**; rankings are local to analyzed coverage. Physical 4D registration and validated well-to-seismic ties: **N/A**.
